# 🧮 Criando uma Calculadora Simples em Python  

Este código implementa uma calculadora interativa que permite ao usuário realizar operações matemáticas básicas de forma intuitiva.  

## 🔹 Entrada de Dados  
O programa começa solicitando dois valores numéricos do usuário, garantindo que sejam inteiros. Em seguida, apresenta um menu de opções para que o usuário escolha qual operação deseja realizar:  
- **1** → Adição  
- **2** → Subtração  
- **3** → Multiplicação  
- **4** → Divisão  

## 🔹 Processamento e Lógica  
Com base na escolha do usuário, o código utiliza uma estrutura condicional (`if-elif-else`) para executar a operação correspondente e exibir o resultado.  

## 🔹 Saída de Dados  
O programa exibe o resultado da operação escolhida, concluindo a interação. Caso o usuário insira um número inválido, o código não possui um tratamento de erro, o que pode ser uma melhoria futura.  

## ✅ Possíveis Melhorias  
- Adicionar tratamento de erros para evitar falhas caso o usuário insira valores inválidos.  
- Implementar um loop para permitir múltiplas operações sem precisar reiniciar o programa.  
- Expandir as operações disponíveis, como exponenciação e cálculo de resto da divisão.  

Esse código é um ótimo ponto de partida para aprender sobre entrada e saída de dados, controle de fluxo e operações matemáticas em Python. 🚀
